# Airline Management System

A Java-based airline management system developed as a group project.

## Overview

This project focuses on managing airline information and analysing flight routes using graph data structures and algorithms.

## Technologies Used

- Java
- JavaFX
- Graph Data Structures
- Graph Traversal Algorithms
- NetBeans IDE

## Main Features

- Airline and airport management
- Flight information management
- Flight route analysis
- Graph traversal
- Flight route visualisation

## Project Structure

The `src` folder contains the Java source files:

- `AirlineSystem.java`
- `Airport.java`
- `Flight.java`
- `FlightGraph.java`
- `FlightMapApp.java`
- `GraphTraversal.java`

## Installation and Setup

1. Install JDK 20 or a compatible Java version.
2. Install Apache NetBeans IDE.
3. Clone or download this repository.
4. Open the project in NetBeans.
5. Ensure the JavaFX libraries in the `lib` folder are configured.
6. Run `airlinesystem.FlightMapApp` to start the application.
